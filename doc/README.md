# Документация spoof_gaz

Учебный стенд **только для PX4 SITL + Gazebo Harmonic**. Все команды выполняются в Linux (для Windows — терминал Ubuntu в WSL2), а не на настоящем БПЛА. Начните с [инструкции по установке](INSTALL.md), затем переходите к [запуску экспериментов](USAGE.md) и [обзору исходного кода](ARCHITECTURE.md).

| Документ | Для кого и зачем |
| --- | --- |
| [Отчёт по проекту (Word)](Отчёт_по_проекту_spoof_gaz.docx) | Для чтения без изучения кода: цели, устройство стенда, три схемы, ход эксперимента, подтверждённые результаты и ограничения |
| [INSTALL.md](INSTALL.md) | Новому пользователю: PX4, Gazebo, Python, локальный venv, IMU patch и проверки |
| [USAGE.md](USAGE.md) | Оператору: безопасные проверки, GPS/IMU/both, периодический режим, ULog и диагностика |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Разработчику: модули, поток данных, жизненный цикл, точки расширения, тесты |
| [px4-gz-imu-topic.patch](px4-gz-imu-topic.patch) | Необходимое локальное изменение PX4 для полноценного IMU-режима |

Исходное подробное описание параметров также есть в [основном README](../README.md); актуальный список аргументов выдаёт `python3 run_test.py --help`.

> Скрипты предназначены для собственных исследовательских симуляций. Они не должны применяться к физическим аппаратам, чужим сетям или инфраструктуре.
