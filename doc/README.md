# Документация spoof_gaz

Стенд для локальных экспериментов с **PX4 SITL + Gazebo Harmonic** под
**WSL2 Ubuntu 24.04**. Все команды выполняются в терминале Ubuntu.
Рабочий каталог по умолчанию — `~/_spoof_gaz`; другую копию можно использовать,
заменив этот путь в командах. PX4 ожидается в `~/PX4-Autopilot`.

| Документ | Назначение |
| --- | --- |
| [INSTALL.md](INSTALL.md) | Установка зависимостей, подготовка PX4/Gazebo и venv, патчи всех поддерживаемых датчиков |
| [USAGE.md](USAGE.md) | Меню, чистый полёт, GPS/IMU/mag/baro, время, серии маршрутов, CSV/PNG и неполадки |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Модули, поток данных, запуск и остановка, точки изменения кода и тесты |

Краткое описание проекта находится в [основном README](../README.md).
Актуальные параметры доступны через `python3 run_test.py --help` и справку
отдельных публикаторов. Патчи внешнего PX4 и порядок их применения находятся
в [patches](../patches/README.md).

В `doc/` хранятся **только `.md` файлы**. Исходники, патчи, бинарные отчёты,
кэш и результаты запусков размещаются вне этого каталога. `logs/` и `venv/`
локальны и исключены из Git. Эксплуатационные сведения поддерживаются в
Markdown; Word-отчёт для работы проекта не требуется.
