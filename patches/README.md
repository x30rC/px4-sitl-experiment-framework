# Патчи PX4 GZ bridge

Эти файлы изменяют внешний репозиторий PX4. Порядок подготовки и сборки
описан в [INSTALL.md](../doc/INSTALL.md#4-патчи-px4-для-imu-mag-и-baro).
Проверенная исходная ревизия: `0bb36a30ed4390f327c04f8f5d7c5cdcb8e9d235`.

| Патч | Назначение |
| --- | --- |
| [px4-gz-imu-topic.patch](px4-gz-imu-topic.patch) | Переменная `PX4_GZ_IMU_TOPIC`, подключение `<cstdlib>` и защита от повторного IMU timestamp |
| [px4-gz-mag-baro-topic.patch](px4-gz-mag-baro-topic.patch) | Переменные `PX4_GZ_MAG_TOPIC` и `PX4_GZ_BARO_TOPIC` |

Для GPS и чистого полёта патчи не нужны. Для IMU примените первый патч.
Для mag/baro примените **оба по порядку**: второй использует `std::getenv`
из заголовка `<cstdlib>`, добавляемого первым. Для всех датчиков также нужны оба.

Перед каждым применением выполните `git apply --check`. Если изменение уже
установлено или версия PX4 отличается, проверьте diff и совместимость вручную.
После патчей требуется пересборка PX4. `run_test.py` сам задаёт переменные
окружения выбранных датчиков при управляемом запуске PX4.
